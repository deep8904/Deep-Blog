# Publishing a note

Create a new Markdown file in this folder using a lowercase kebab-case filename:

`what-the-first-prototype-taught-me.md`

Copy `_post-template.md`, complete the frontmatter, and set `draft: false` only when the note is ready to publish.

Files beginning with `_` are never listed or routed, so the template remains private.

Optional image metadata should only be added after a real file exists in `public/`.
Inline article images should use descriptive alt text, responsive sizing, and short factual captions.

# Visual reference analysis

## Framer references

### Write
Useful qualities:
- Writing-first information architecture.
- Restrained navigation.
- Serif and sans-serif contrast.
- Clear archive and article hierarchy.

### Nitro
Useful qualities:
- Large typography that becomes part of the composition.
- Strong card-based responsive recomposition.
- Small authored labels and a confident personal identity.

### Opus
Useful qualities:
- Modular editorial grids.
- Controlled asymmetry.
- Large type paired with compact supporting copy.
- Motion used to support hierarchy.

## Uploaded screenshot findings

The supplied desktop, tablet, and mobile screenshots repeatedly use:
- Layouts that recompose rather than merely shrink.
- Strong typographic scale changes.
- Modular cards with intentionally different roles.
- Small labels and metadata to create structure.
- A limited palette with one dominant accent.

## Revised synthesis

Draft State keeps the useful editorial hierarchy from the references, but moves away from oversized template-like panels and decorative dashboards. The current system uses a dark Night palette, wide ruled sections, restrained technical grid surfaces, and a typography-led featured article band. It feels closer to an independent personal publication than a landing page.

Nothing from the reference sites has been copied verbatim. The project uses their principles to build an original personal-blog system.

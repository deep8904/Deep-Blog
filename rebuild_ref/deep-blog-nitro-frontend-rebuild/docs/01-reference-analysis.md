# 01 — Reference Analysis

## What gives the reference its identity

### 1. Near-black editorial canvas
The background behaves as the page, not as empty space around cards. There are no
cream containers floating inside a browser-sized gutter. Content is placed directly
on a deep canvas and organized with thin structural lines.

### 2. Quiet navigation
The wordmark is small. Navigation is small. The active item uses one controlled accent.
The header never competes with the main content.

### 3. Technical grid
Long vertical guides and occasional horizontal rules establish rhythm. Small circles,
crosshairs, and line endpoints act as editorial notation rather than decoration.

### 4. Oversized but restrained typography
Headings are large, plain, and sans-serif. The design does not need an italic serif
headline to feel editorial. Line breaks are deliberate and the visual hierarchy comes
from scale, alignment, and whitespace.

### 5. Media-led rows
Portfolio items use a strong title strip and a large media rectangle. On narrower
screens, the content becomes a simple vertical stack without losing identity.

For Deep Blog, the same grammar should become:
- article title strip
- article metadata
- future photography or event image
- short article description
- large click target

### 6. Asymmetric information placement
Secondary notes, metadata, section markers, and annotations sit in narrow side columns.
The main content remains dominant.

### 7. Responsive redesign, not shrinking
Desktop, laptop, tablet, and phone screenshots show different compositions. The phone
layout does not preserve every desktop decoration.

## What not to copy

- Nitro branding or wordmark
- orange, cobalt, yellow, or project-specific palettes
- project names, copy, images, icons, and personal details
- exact pixel measurements
- exact portfolio page structure
- Framer promotional widgets
- form behavior without a real submission backend

## Translation to a personal blog

| Reference device | Deep Blog translation |
|---|---|
| Project card | Article feature card |
| Projects page | Writing archive |
| About experience rows | Personal timeline / areas of practice |
| Notes image list | Essays and field notes |
| Contact page | Optional contact route only with real contact data |
| Grid ornaments | Reading progress, section markers, metadata guides |
| Green “get template” accent | Custom mineral-green active state |
